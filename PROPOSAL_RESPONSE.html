2. Multi-Tenant RLS Implementation

Multi-tenancy is enforced at the database level using Supabase Row Level Security, ensuring complete data isolation between organizations.

-- Enable RLS on all tables ALTER TABLE documents ENABLE ROW LEVEL SECURITY; -- Policy: Users only access documents in their organization CREATE POLICY "org_isolation" ON documents FOR ALL USING ( site_id IN ( SELECT id FROM sites WHERE organization_id = get_user_organization_id() ) OR EXISTS ( SELECT 1 FROM user_profiles WHERE id = auth.uid() AND role = 'admin' ) );

Role-Based Access Matrix

Resource Admin Org Admin Site Manager

4. File Security: Risks & Mitigations

Risk Impact Mitigation
Unauthorized Access Data breach ✅ Storage RLS policies enforce tenant isolation
Path Traversal Attacks Access others' files ✅ UUID paths, not user-provided names
Malicious File Upload Server compromise ✅ MIME validation, extension whitelist
File Size Attacks (DoS) Service disruption ✅ 10MB limit client + server side
Direct URL Access Bypass controls ✅ Private bucket + signed URLs (15 min)
Audit Trail Gaps Non-compliance ✅ All actions logged to audit_logs
